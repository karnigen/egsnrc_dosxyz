# IAEA Header Samples

- `ex1.IAEAheader` and `ex2.IAEAheader` are sample input headers.
- `ex_all.IAEAheader` is a combined-header sample.
- `ex_all_previous.IAEAheader` preserves the earlier header that was named `ex_all.IAEAheader_zal`.

The matching binary `.IAEAphsp` files are not included, so these samples demonstrate header parsing and writing, not phase-space joining.
